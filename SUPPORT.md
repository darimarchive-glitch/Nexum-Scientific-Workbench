# Suporte

## Versão suportada

A linha estável atual é **Nexum 7.0.x**. Previews e releases históricas são mantidas para rastreabilidade, mas correções devem ser reproduzidas primeiro na versão estável mais recente.

## Relatar um problema

Use o rastreador de issues do repositório e inclua, quando possível:

- versão exata do Nexum;
- sistema operacional e arquitetura;
- artefato instalado;
- passos mínimos para reproduzir;
- resultado esperado e resultado observado;
- logs ou mensagens de erro relevantes;
- indicação de uso de GPU nativa ou fallback gráfico, quando o problema for de renderização.

Remova dados pessoais, credenciais, caminhos sensíveis e conteúdo confidencial antes de anexar logs.

## Problemas científicos

Para resultados numéricos, informe entradas, unidades, modelo utilizado e uma referência independente ou caso analítico quando existir. Uma diferença numérica sem essas informações pode não ser suficiente para distinguir bug, hipótese diferente ou limite de modelo.

## Licenciamento e implantação

Questões sobre uso institucional/comercial, implantação ou redistribuição devem seguir [COMMERCIAL.md](COMMERCIAL.md). Não publique contratos, preços negociados ou informações comerciais confidenciais em uma issue pública.

## Segurança

Vulnerabilidades e relatos que possam permitir exploração não devem ser publicados como bug comum. Consulte [SECURITY.md](SECURITY.md).
