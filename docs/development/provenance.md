# Proveniência e revisão da atualização

A base desta entrega é o projeto Nexum Scientific Workbench, versão 6.8.1, commit `1618db4c993eb71f371083b756e7429fc774e78f` do repositório fornecido pelo mantenedor.

As novas implementações em `nexum/lab/`, a interface do laboratório, os testes correspondentes, a preparação macOS, a padronização dos pacotes e a documentação desta atualização foram produzidos com assistência de IA nesta sessão. As modificações de integração atingem também identidade, caminhos, catálogo, interface principal, worker químico e scripts de empacotamento. Não foi auditada a origem de cada linha anterior à base.

O pacote contém verificações automatizadas e um registro do que foi efetivamente executado. Isso não substitui revisão humana de arquitetura, ciência, acessibilidade e comportamento nativo. O mantenedor deve revisar especialmente os limites dos modelos, persistência de trabalhos reais e instalação por usuários sem ambiente de desenvolvimento.

Não foram criados commits, PRs, releases ou submissões de loja nesta entrega. A documentação de distribuição explica a restrição atual do Flathub sobre manifestos assistidos por IA.
