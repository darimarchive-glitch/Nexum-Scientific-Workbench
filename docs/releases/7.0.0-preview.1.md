# Nexum 7.0.0-preview.1

Prévia para avaliação acadêmica. Inclui laboratório com projetos, dados experimentais, construção molecular, fluxos de análise, planejamento experimental, controle de qualidade, incerteza, balanços de processo e relatórios. Mantém 43 calculadoras, 10 bancadas experimentais e 5 análises, com 16 capacidades adicionais no laboratório.

Documentação reorganizada em desenvolvimento, ciência, uso, distribuição e histórico de versões. Relatórios duplicados e automações de publicação específicas de versões antigas foram removidos; testes e histórico Git foram preservados.

## Downloads

- Windows x86_64: arquivo `-setup.exe` com atalhos.
- Linux x86_64: arquivo `.flatpak` independente. Instale com `flatpak install --user caminho-do-arquivo.flatpak`.
- macOS: arquivo `.dmg` da arquitetura do computador; arraste Nexum para Aplicativos.
- Código-fonte: arquivo `-source.zip`.
- Integridade dos arquivos: `SHA256SUMS.txt`.

A publicação automática exige sucesso nos testes científicos e nas verificações dos pacotes nativos. Esta prévia não possui assinatura comercial do Windows nem notarização Apple; o sistema pode apresentar aviso de desenvolvedor não identificado. O pacote Linux não equivale à inclusão no catálogo Flathub.

Modelos, hipóteses e limites estão em `docs/science/laboratory-methods.md`. Resultados de simulação não substituem validação experimental. A avaliação manual da interface em diferentes computadores continua necessária.
