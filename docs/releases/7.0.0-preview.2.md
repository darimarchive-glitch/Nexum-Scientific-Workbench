# Nexum 7.0.0-preview.2

Revisão pontual de aparência, sem reorganização geral das ferramentas.

- Menu de sessões e aparência: seguir o sistema, claro ou escuro, com preferência salva.
- O preset Bastões preserva o tema do aplicativo e sincroniza os controles laterais.
- Visualizadores de comparação também acompanham a mudança de tema.
- Fundo 3D acompanha a cor de fundo do GTK; controle duplicado de reenquadramento removido.
- Testes de regressão de tema e presets, além dos testes científicos e dos aplicativos empacotados.

Os instaladores desta release são publicados somente após os testes nativos de Windows, Linux/Flatpak e macOS Intel/Apple Silicon. Trata-se de uma prévia de desenvolvimento. Os pacotes não possuem assinatura comercial Windows nem notarização Apple. O Flatpak é independente; a distribuição pelo Flathub é uma etapa separada.

Escolha o arquivo correspondente ao seu sistema e arquitetura. `SHA256SUMS.txt` contém os hashes dos instaladores e do código-fonte.
